## Сделано за день

- Обновлены окна Сайта и SabyDoc по L01–L12. Общая левая панель имеет состояния collapsed / overlay / docked; варианты содержимого — «Страницы» и «Оглавление».
- Временная панель раскрывается без задержки по наведению и доступна с клавиатуры. Она не сдвигает документ. Закреплённая занимает 366 px в раскладке: 350 px панели и внешние отступы.
- Закрепление, открепление и временное закрытие не сбрасывают выбранную строку и раскрытые ветки. Откреплённая панель остаётся временной до ухода указателя или клавиатурного фокуса.
- У Сайта одна «Страница 1», в чтении левой панели нет. У SabyDoc пять заголовков; экспандер управляет веткой отдельно от выбора, текст заголовка прокручивает документ.
- По уточнению пользователя команда общего раскрытия меняется на «Свернуть все», когда раскрыто больше одной ветки.
- Согласован адаптив по правилу 30% от рабочего фрейма 1180/820 px. Закрепление доступно от 1246 px в чтении и от 1354 px в редакторе. При сужении панель сворачивается; после расширения доступно ручное закрепление. В редакторе резервируется место для обоих сайдбаров, даже при закрытой правой широкой панели. Приоритет числового правила подтверждён пользователем при расхождении с примером.
- SabyDoc переносит текст в узкой рабочей области без уменьшения шрифта. Широкое представление сохраняет исходный документ-ассет.
- В форматировании команды скрываются по одной справа налево при нехватке места. Последние три — аудиолинии, SabyGPT и «⋯» — остаются вместе с разделителем. Скроллбара нет; меню скрытых команд пока не реализовано по просьбе пользователя.
- У закрепления левой панели отступы сверху и справа по 8 px.
- «Сохранить» возвращает тот же файл в чтение у Сайта, SabyDoc и Схемы. Серверных сохранений и мутаций данных нет. Ширина «Сохранить» и «Изменить» одинакова — 116 px.
- При переходе SabyDoc из редактора в чтение текст и прокрутка остаются на месте. Верхний отступ чтения 56 px компенсирует тулбар 44 px и отступ редактора 12 px.
- Во всех шапках масштаб отображается как 100%. Разделитель после отмены/повтора имеет высоту 24 px.
- Обновлены состояния навигационных кнопок правого тулбара: 44×48 px, подложки hover/active и оранжевый маркер справа. Кнопка «⋯» — 32×32 px. Команды без реализованного действия не переключаются в выбранное состояние по клику.

## GitHub и публикация

Перенесён только этот проект: приложение, шрифты, ассеты, сервер запуска и проектная документация. `.gitignore` исключает локальные рендеры Figma, проверочные скриншоты и исходные JPG-референсы из корня.

Workflow `.github/workflows/pages.yml` запускает `npm run check` и публикует только содержимое `app` при push в `main`. GitHub Pages настроен на GitHub Actions. Локальная папка связана с `origin/main`.
