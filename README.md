# Реестр файлов и Окно конструктора

Настольная интерактивная демка SabyDesign: 12 файлов и контекстные превью. Чтение доступно для 11 файлов; редактор — для Сайта, SabyDoc, Схемы и Дашборда. Опрос пока открывается в превью. Данные демонстрационные; серверные операции изменения файлов не выполняются.

## Демо и публикация

[Открыть демку на GitHub Pages](https://pupsik3.github.io/builder-file-standarts/).

Workflow `.github/workflows/pages.yml` проверяет JavaScript и публикует только содержимое `app` при каждом push в `main`. Также доступен ручной запуск в GitHub Actions. Локальные рендеры и проверочные скриншоты исключены из Git.

## Локальный запуск

Нужен Node.js. Из папки проекта выполните `npm start` и откройте `http://127.0.0.1:4182/`. Установка зависимостей не требуется. Переменная окружения `PORT` позволяет задать другой порт.

Маршрут в интерфейсе — «Мой диск → Мои документы → файл». Карточка любого типа, кроме Опроса, открывает чтение. Кнопка «⋯» на карточке открывает превью с командами. Из чтения и превью четырёх поддерживаемых типов можно перейти в редактор. «Сохранить» возвращает тот же файл в чтение.

`npm run check` проверяет синтаксис JavaScript. Папка `app` содержит статические файлы, которые раздаёт локальный сервер.
