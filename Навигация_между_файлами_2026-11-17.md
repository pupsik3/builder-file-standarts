# Навигация между файлами — 17 ноября 2026

Локально: http://127.0.0.1:4182/. Запуск: `npm.cmd start`. По запросу пользователя итерация отправляется в `main`; демка обновляется штатным workflow GitHub Pages: https://pupsik3.github.io/builder-file-standarts/.

## Реализация

- Общая навигация вынесена в `app/file-navigation.js` и `app/file-navigation.css`, подключена к существующим `renderViewer` и `showViewer`.
- Порядок берётся из видимых карточек текущего реестра при открытии вьювера. Отдельного порядка по типам нет. Сортировка/фильтрация в текущем прототипе визуальны; будущие изменения порядка или видимости карточек будут учтены при открытии.
- Признак `canReadFile` общий для карточек, стрелок и ленты: поддерживаемый тип и источник содержимого. Опрос виден в ленте с `aria-disabled`, но не открывается и пропускается стрелками. Границы не зациклены.
- Капсулы 28×48 px стоят в 12 px от краёв окна по вертикальному центру. Прозрачность фона: .2 / .25 / .3 для покоя / hover / press. По последнему замечанию пользователя левый шеврон дополнительно смещён на 2 px влево; область нажатия и капсула сохранены.
- Миниатюры 72×72 px, промежутки и отступы 8 px. Лента содержит все 12 файлов; текущий отмечен оранжевым маркером. Нет названий и команд карточек. Кадрирование и отдельные значки типов повторяют компоненты Figma. Фото использует уже существующий полноразмерный ассет `e82b3.png`; прочие изображения переиспользованы из записей файлов.
- Кнопка 48×24 px, лента 968×88 px при 1600×900. Появление/закрытие — translate, 300 ms ease-out по Prototype; при prefers-reduced-motion движение выключено. Быстрые повторные нажатия меняют одно состояние одного элемента.
- По уточнению пользователя и в закрытом, и в открытом состоянии непрозрачность шевронов .6; hover/focus — 1. Подложка rgba(8,8,8,.6).
- Открытие по клику согласно заданию. В Figma у исходного Default/hover указан ON_HOVER → click; этот триггер не перенесён, поскольку пользователь явно задал открытие кликом. Закрытие в Prototype — ON_CLICK. Выбор файла не закрывает ленту.
- Лента сохраняет прокрутку между файлами; выбранное превью автоматически остаётся в видимой области. На узком десктопе — горизонтальная прокрутка, размеры миниатюр не меняются.
- В редакторах навигации нет в DOM. Вход в редактор сбрасывает ленту в закрытое состояние; после «Сохранить» стрелки и кнопка возвращаются, лента закрыта. Это заменяет первоначально предложенное сохранение открытой панели.
- Переключение вызывает существующее открытие по ID в чтении и очистку ресурсов. Выбор текущего файла ничего не пересоздаёт. Меню прежнего файла закрывается. Навигация страниц/слайдов/листов и правила левых панелей сохранены.
- Escape сначала закрывает меню, затем открытую ленту; фокус возвращается на её кнопку. Закрытые превью inert. Выход из вьювера использует прежнее восстановление позиции и фокуса реестра.

## Проверено

- Браузер: все 11 доступных файлов стрелками вперёд и назад, правильные ID и режим read. Опрос между сайтом и XLSX пропускается в обоих направлениях. У видео нет предыдущей, у секции нет следующей. Опрос получает фокус с клавиатуры, Enter не меняет текущий файл.
- Выбор превью, сохранение открытой ленты между файлами, маркер текущего файла. Повторный выбор играющего видео сохраняет воспроизведение и время (0.24 → 0.55 с), после перехода к фото плеер удалён через существующий cleanup.
- Все редакторы: сайт, SabyDoc, схема, дашборд — навигации нет; после сохранения read, лента закрыта и inert.
- PPTX: выбран слайд 2, нижний счётчик согласован; закрепление/открепление работает. XLSX: выбран настоящий лист «Воронка». DOCX: выбрана страница 2, scrollTop 1171.
- Открытое меню при переключении закрывается. Шесть быстрых нажатий кнопки оставляют одну ленту в ожидаемом состоянии; рабочая область не меняет высоту.
- 1600×900: стрелки x=12 и x=1560, y=426, 28×48; лента x=316, y=812, 968×88. Все изображения загружены, размеры миниатюр 72×72.
- 900×700: лента 792 px, содержимое 968 px, последний файл полностью виден при scrollLeft 176; возврат к первому доводит scrollLeft до 0. Внешнего горизонтального переполнения нет.
- Реестр при 1100×400: scrollTop 145 сохраняется после переключения и выхода; фокус возвращается на исходную карточку «Новая секция».
- Границы сетки: 1109→4, 1110→5, 1578→5, 1579→6 колонок. Сетка не менялась.
- Покой/hover/press стрелок измерены в браузере: rgba(0,0,0,.2/.25/.3). Шевроны кнопки в покое .6.
- `npm.cmd run check`, `npm.cmd test`, `git diff --check` прошли. Два теста общей логики покрывают иной порядок, опросы у краёв/между файлами, единственный доступный файл и пустой список. Сценарий одного файла и опросов у краёв проверен на уровне общей логики, а не изменением данных рабочего реестра в браузере.
- Новых ошибок/предупреждений в консоли нет. Скриншот: `.design-context/qa-1711/file-navigation.jpg` (локальный материал проверки).

Неподтверждённых ID и нерешённых вопросов нет. Системное переключение настройки уменьшения движения не выполнялось; поддержка реализована через media query.
