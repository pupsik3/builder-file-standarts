# Вьюверы новых типов — 16 ноября 2026

Локальный адрес: http://127.0.0.1:4182/. Запуск: `npm start`. Публикация этой итерации выполняется штатным workflow GitHub Pages после отправки изменений в `main`.

## Реализовано

- DOCX и PDF: отдельные представления двух страниц, непрерывная прокрутка, выбор страницы, общая левая панель collapsed / overlay / docked. По последнему уточнению пользователя специальная страница DOCX исключена.
- PPTX: три готовых слайда, выбор в левой панели и нижней линии, предыдущий слайд с границей первого, согласованный номер и счётчик. Закрепление вписывает весь слайд, временная панель его не сдвигает. Демонстрация и дополнительная команда рядом со счётчиком визуальные.
- XLSX: HTML-таблица с буквенными колонками и номерами строк, объединённые заголовки, активная ячейка, две вкладки и внутренняя прокрутка по двум осям. Данные, ширины и высоты получены из предоставленной книги. Формулы не пересчитываются: используются её готовые сохранённые значения.
- Фото: исходное изображение Figma, вписывание без обрезки, собственный вариант шапки.
- Видео: локальный `sample-5s.mp4`, скопированный из пользовательского `Видео.mp4`. Реальные play/pause, полоса перемотки, mute/volume, время, окончание и fullscreen. Продолжительность из метаданных — 5.758549 секунды. Без автозапуска. При закрытии вызывается pause и удаляется плеер. Локальный сервер поддерживает byte ranges для MP4.
- Секция: отдельный блок с текстом, кнопкой, Алексеем и изображением листьев. Содержимое собрано отдельно от оболочки, текст — HTML; для фотографий используется соответствующий исходный ассет Figma с кадрированием.
- Дашборд: шесть виджетов в чтении, отдельная раскладка редактора с областью вставки, шапка и тулбар по режиму. Оба входа в редактор, прямой вход из превью и возврат через «Сохранить». Меню не меняет раскладку.

## Переиспользование и границы

Общие `renderViewer`, header / toolbar, `iconButton`, `commandList`, `panelClose`, `renderOutline` / `bindOutline` / `syncOutline`, запись файла и восстановление фокуса. Состояния панели, выбора страницы/слайда и листа разделены. Типовые команды сохраняют идентичность в разных поверхностях.

Восемь новых типов используют одну оболочку; содержимое вынесено в `file-content.js`, дашборд — в `dashboard.js`. Согласованные карточки и сетка не изменялись. Кнопка «Сообщения» остаётся в трёх прежних вьюверах; у новых типов состав нижней зоны соответствует новым кадрам.

«Изменить» у DOCX/PDF/PPTX/XLSX/фото/видео/секции визуальна и не открывает редактор. Поиск, масштаб, демонстрация слайдов, камера, добавление виджетов, скачивание, доступ и другие операции с данными остаются визуальными. У DOCX, PDF и фото подключён поворот влево/вправо на 90°; он меняет представление без изменения исходного файла. В видео кнопок поворота нет. По уточнению пользователя шаговые кнопки видео и скорость тоже визуальны. Снимки кадра не создаются. Опрос сохраняет только прежнее превью.

Для новых меню пользователь разрешил команды соответствующего превью без «Переместить». Меню дашборда взято из собственных кадров чтения/редактора.

## Ограничения и продолжение

После замечаний по шапке добавлен общий разделитель высотой 24 px после новых групп команд (DOCX/PDF/фото/XLSX/секция). У видео удалены повороты, кнопка и ползунок звука размещены в одном flex-ряду с остальными контролами; измеренные центры всех кнопок и громкости совпадают (872 px при 1600×900). Проверены повороты фото 90/180/270/0, обратный поворот с клавиатуры, вписывание в рабочую область. В PDF поворачиваются обе страницы, их размеры в раскладке меняются с 876×1159 на 1159×876, сохраняются выбор страницы и работа панели/меню. Проверка узкого окна 1100×700 не выявила внешнего горизонтального переполнения. `npm run check` и `git diff --check` прошли; новых console error/warn нет.

У XLSX восстановлены верхние скругления и тень рабочей области: 0/0/8 px, чёрный с непрозрачностью 6%, по узлу 32359:43001. При viewport 2504×1243 измерены левый край 8 px и верхние радиусы 8 px. Общий отступ оболочки сохранён без удвоения.

Проверены полный оборот, обратное направление и клавиатура, выбор второй страницы, закрепление/открепление панели и меню с сохранением ориентации.
